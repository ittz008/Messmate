# 🍽️ MessMate – Mess Management System

**MessMate** is a student-friendly Mess Management System developed as a college group project at Lovely Professional University (LPU).

The website provides a simple platform where students can check daily meals, explore weekly menus, view sample attendance and payment details, read announcements, and share feedback.

## 🌐 Live Demo

[Visit MessMate Website](https://lpumessmgmt.netlify.app/)

## ✨ Features

- **Today's Menu:** View daily breakfast, lunch, and dinner.
- **Weekly Menu:** Explore the meal schedule for the entire week.
- **Meal Attendance:** View sample monthly attendance details.
- **Announcements:** Check important mess updates and notices.
- **Monthly Payment:** View sample mess bill information.
- **Student Feedback:** Submit suggestions and complaints through a feedback form.
- **About Section:** Learn about the project and its purpose.
- **FAQs:** Find answers to common questions.
- **Responsive Design:** Simple and user-friendly website interface.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and layout
- JavaScript – Interactive features

## 🎯 Project Objective

The main objective of MessMate is to make mess-related information easily accessible to students. It brings meal schedules, announcements, attendance details, and feedback options together in one place.

## ⚠️ Note

This is an educational demonstration project. Attendance, payment, and menu information are sample data. The website does not process real payments or permanently store feedback in a database.
